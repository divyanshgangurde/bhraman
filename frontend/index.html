हर सफ़र, एक कहानी — Every journey, a story

One itinerary, priced door to door: flight vs train vs bus, plus hotel and the last mile. Totals are computed in code, never invented by the model. Sample data only in this demo — no live Duffel / LiteAPI yet.

Sets earliest onward departure = arrival + 4h.

Sample data covers BOM → PNQ and PNQ → DEL only. Other routes will return no results gracefully — that is honest sample-data behaviour, not a crash.

How to read a result: LIVE = live API (tier 1)   INDICATIVE = offline dataset / sample (tier 2)   SAMPLE • Deep-link = deep-link only (tier 3). Train availability is always INDICATIVE — there is no public IRCTC booking API. The ranker rejects onward legs before the buffer, filters over-budget totals, and flags baggage shortfalls; it never hides them.

API: POST /api/plan · GET /api/demo-presets · GET /health · See README-FRONTEND.md to run it.
